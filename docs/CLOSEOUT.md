# 实验收尾与交接

2026-11-09 收尾，源码版本为 `0.7.0b1`。本轮暂停继续开发及硬件验证，保留集成、
三款插座的协议研究、扫码工具和离线测试，供参考或后续接手。

## 本轮实现

- 首次连接优先：只对尚未进入设备业务操作的已知瞬时建连错误，最多重新建连一次。
  重试前确认旧连接已断开，使用全新客户端及密码会话，并受冷却和总工作时间预算限制。
- BlueZ 在超时后暂时丢失设备对象时，等待已有扫描器在同一适配器重新发现；
  不清缓存、不主动启动新扫描、不接管其他连接。
- 后台只读重试可给手动请求让路，避免内外层重试相乘；进行中的事务不会被强制打断。
- 计量版可选保留已鉴权连接，默认关闭。空闲保留范围为 1-120 秒，
  满 300 秒或 64 次协议请求即更新会话；空闲到期、错误和卸载时清理连接。
- 开关快速路径只读取继电器、按需写入、独立读回确认，随后低优先级刷新完整数据。
  开关验证不会把旧计量和设置数据标记为新鲜。设置仍走完整校验路径。
- 保留手动优先、FIFO、仅连续重叠相同请求合并；不自动重放结果不确定的写入。
  新增安全错误码、失败阶段和数值耗时诊断，不输出密钥或原始鉴权数据。

连接复用只减少已有会话下的后续操作开销，不能解决首次连接本身的延迟。
未把偶发连接失败解释成蓝牙硬件只能连接一台设备，也未加入强制单连接的使用限制。

仍未验证或不保证：

- 长期运行稳定性、大规模多设备并发、其他适配器及固件兼容性。
- 所有连接故障的实机恢复；故障分支主要通过离线测试，未故意干扰生产蓝牙环境。
- 普通版的可选连接复用、普通版定时的 HA 控件、炎米 Y1 的 HA 添加入口。
- kWh 用电量统计、本地定时和循环定时的 HA 功能。独立研究代码不等同于集成已开放功能。

## 后续接手

首先运行离线检查，不需要 HA、蓝牙或小米登录：

```sh
python -B -m unittest discover -s tests -v
python -B -m unittest discover -s tests/protocol -v
python -B -m unittest discover -s research/yutai_fsov7m -v
python -B -m unittest discover -s research/wiing_v7icm -v
python -B tools/build_release.py
git diff --check
```

硬件实验应另行授权、先备份，并仅在明确允许的空载设备上执行写入。
遇到慢响应，区分排队、建连、服务发现、订阅、鉴权和业务读写耗时，不以提高重试次数代替诊断。
不要以本次小样本结果宣称兼容所有 Mesh 插座或保证即时响应。

本仓库不应包含真实设备密钥、扫码会话、家庭实体和地址、HA 配置或备份。
不要为追求“全部源码”上传整个工作目录；个人测试记录及部署资料应留在本地受保护目录。
HA 中移除设备与源码归档是独立操作，本文档不代表已经移除了任何运行中的设备。
