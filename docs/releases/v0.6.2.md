# Yutai BLE v0.6.2

本版本改进简体中文界面的型号选择、填写说明和错误提示，并把对应说明补充到 README。
已有设备配置、内部型号值和实体唯一 ID 保留，无需删除设备或重新扫码。

## 界面改进

- 添加页面的型号选择显示 **禹泰电工计量版（fsov8m）** 和
  **禹泰电工普通版（WY-E802 / fsov7m）**，便于与扫码结果核对。
- 为设备名称、蓝牙地址、插座型号和蓝牙长期密钥增加填写说明，明确密钥需要
  **64 个十六进制字符（32 字节）**。
- 补充配置失败、轮询设置和设备操作失败的中文提示；英文界面仍有对应的英文翻译。
- README 增加中文名称与完整型号对照表、字段填写示例及更新后刷新界面的说明。

本次仅改进用户提示及型号选择控件。协议型号仍保存为 `yutai.plug.fsov8m` /
`yutai.plug.fsov7m`；BLE 控制、读回确认、排队、失败退避和禁止自动重发写入的行为保持一致。

## 如何更新

1. 在 HACS 中打开 **Yutai BLE**，执行 **更新信息 → 重新下载**，选择 `v0.6.2`。
   如果 HA 的“设置 → 更新”已出现该集成，直接安装更新即可。
2. **重启 Home Assistant**。
3. 再次打开添加页面。若仍显示旧文案，刷新浏览器；确认当前 HA 用户使用简体中文。

手动安装者下载 **`yutai-ble-v0.6.2.zip`**，替换 `custom_components/yutai_ble` 后重启 HA。
已有设备不必重新添加。独立 Windows 扫码包随版本提供，本次没有改动其功能。

## 下载与校验

- `yutai-ble-v0.6.2.zip`：HA 组件。
- `yutai-ble-qr-windows-v0.6.2.zip`：独立 Windows 扫码工具。
- `SHA256SUMS.txt`：两个 ZIP 的 SHA-256 校验值。

发布由 Python 3.13 / 3.14 离线测试、Home Assistant 2026.10.4 框架检查和 Windows
启动器检查共同把关，上传后核对附件摘要。没有操作正在运行的 HA 或实际插座。

完整填写示例见 [README](https://github.com/jsdfhasuh/ha-yutai-ble/blob/v0.6.2/README.md#添加页面怎么填写)。
