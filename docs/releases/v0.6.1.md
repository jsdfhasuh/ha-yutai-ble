# Yutai BLE v0.6.1

本版本修复 BLE 排队、失败诊断刷新和 Windows 扫码工具安装恢复问题。
已有设备配置和实体唯一 ID 保留，更新后重启 Home Assistant 即可，无需重新配对或扫码。

## 修复内容

- **多设备排队**：后台轮询等待全局蓝牙连接队列时，可以为随后提交的手动命令让路，
  避免手动操作被自己设备的后台轮询阻塞。保留手动命令的先后顺序、断连冷却，
  不打断已经开始的蓝牙事务。
- **连续失败诊断**：连续读取或控制失败后，继续更新失败次数和通信诊断，
  包括控制失败后的第一次轮询失败。设备仍保持不可用，不会因刷新诊断被误报为在线。
- **Windows 扫码工具**：启动前检查依赖；如果此前安装依赖失败但虚拟环境已创建，
  再次启动会重试安装，避免一直跳过安装步骤。

## 如何更新 HA

更新前保留 HA 备份。

- **HACS 安装**：打开 Yutai BLE，执行“更新信息（Update information）”，再选择
  “重新下载（Redownload）”并确认 `v0.6.1`；若“设置 → 更新”已出现该集成，直接安装即可。
- **Marketplace 管理**：在“设置 → 更新”中安装 Yutai BLE 更新。
- **手动安装**：下载组件 ZIP，用其中的 `custom_components/yutai_ble` 替换 HA 中的同名目录。
  最终应有 `/config/custom_components/yutai_ble/manifest.json`。

安装后进入 **设置 → 系统 → 右上角电源图标 → 重启 Home Assistant → 重启**。
保留已有设备条目和 `.storage`。仅刷新浏览器或重新加载集成不能替代代码更新后的 HA 重启。
详细步骤见 [安装、更新与维护](https://github.com/jsdfhasuh/ha-yutai-ble/blob/v0.6.1/docs/INSTALL.md)。

## 验证与范围

- Python 3.13 / 3.14 CI 运行集成、协议、两组研究代码的离线回归测试，并构建安装包。
- Home Assistant 2026.10.4 的真实协调器测试验证连续失败通知。
- Windows CI 使用实际 `cmd.exe` 验证扫码工具依赖安装失败后的恢复。
- 发布流程在上述检查通过后校验安装包、上传附件并验证远端 SHA-256，再公开 Release。

继续支持禹泰普通版 `yutai.plug.fsov7m` 和计量版 `yutai.plug.fsov8m`。
炎米 Y1 仍为独立研究代码；本版本没有新增蓝牙代理、计时或电量统计能力。
本次验证未操作实际插座或正在运行的 HA，真实射频环境下的延迟和恢复表现仍需实机确认。
