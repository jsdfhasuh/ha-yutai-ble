# 禹泰蓝牙插座 · Yutai BLE

Home Assistant 自定义集成，通过本地蓝牙控制禹泰普通版和计量版插座。
仓库同时公开普通版和炎米 Y1 的独立协议测试源码，覆盖此前测试过的三款插座。
它是 **HA 集成（custom integration）**，不是独立 App，也不是 Supervisor 加载项。

**2026-11-09 实验收尾：停止继续硬件测试，保留源码供参考或后续接手。**
当前 `v0.7.0b1` 为实验源码快照，**不是新的稳定发布**。验证结果和限制见[收尾与交接](docs/CLOSEOUT.md)。

该快照增加首次建连阶段诊断和有限重连，并为计量版增加可选的已鉴权连接复用和快速开关回读。
默认关闭复用，已有配置和实体 ID 保留，无需重新扫码。
见下方说明和[更新步骤](docs/INSTALL.md#更新和回滚)。

### 可选连接复用

在计量版集成的选项中设置“保留已鉴权连接（秒）”：0 保持原来的单次连接方式，
1～120 设置空闲保留时间。90 秒可覆盖默认的 60 秒轮询，减少下一次操作的建连和鉴权。
连接使用满 300 秒或 64 次协议请求后更新会话；断连后下次操作重新鉴权。
普通版不启用此路径。保持连接可能占用米家蓝牙直连，需要手机直连时将该选项设为 0。

快速开关仅执行继电器读取、必要时写入、独立回读，验证成功后立即更新开关；
约 1 秒后以低优先级刷新完整计量和设置。快速回读不会更新“最近成功读取”的完整刷新时间，
通信状态属性另列开关验证时间、排队和工作耗时。手动请求继续优先、按序执行，
仅合并连续重叠的相同请求；写入失败不自动重发。设置写入仍走完整校验路径。
该测试版须逐台启用；多连接、不同固件及长期稳定性不作保证。

### 首次连接

通信状态属性提供连接次数和建连、MTU、订阅、鉴权等阶段耗时，失败时保留明确的阶段及安全错误码。
只在蓝牙建连发生已知瞬时错误、尚未进入设备操作且已确认旧连接断开时，允许重新建立一次全新连接。
手动操作的两次建连共用原来的总时间预算；后台读取的重试会让出队列，保留手动操作优先，两种重试不会叠加。
连接超时后若设备缓存暂时消失，仅等待已有扫描重新发现它，不主动清缓存或抢占连接。
鉴权拒绝、校验失败、取消或清理失败不自动重试。
这项改进用于减少首次点击失败，不代表正常首次连接变成半秒；半秒级响应依赖已经鉴权的连接。

## 支持范围

| 项目 | 普通版 `yutai.plug.fsov7m` | 计量版 `yutai.plug.fsov8m` |
| --- | --- | --- |
| HA 添加 | 支持 | 支持 |
| 总开关 | 支持，写入后读取确认 | 支持，写入后读取确认 |
| 指示灯 | 跟随、常灭 | 跟随、反向、常灭、常亮 |
| 通电默认状态 | 关、开、记忆 | 关、开、记忆 |
| 电压/电流/功率 | 不创建未经验证的计量实体 | V / A / W |
| 勿扰、双击倒计时 | 不开放 | 支持 |
| 诊断 | 通信状态、最近成功读取、连续失败次数、输出状态 | 同左 |

每台单独添加，地址、密钥、状态和失败计数独立，两款可以共用同一集成。
当前 HA 控件尚不包含 kWh 电量统计、本地定时或循环定时；普通版定时的研究代码仍在仓库中。

从 **0.5.0** 起，普通版和计量版都可在 HA 表单选择型号后添加。
炎米 Y1 仍只有研究源码，尚未接成 HA 设备入口。
研究代码不会随 HACS 安装，也不会被集成自动加载。下载仓库的 Source code ZIP 可获取三款全部源码。
详见 [型号与验证范围](docs/MODELS.md) 和 [研究源码说明](research/README.md)。
同品牌或名称带有“Mesh”不代表协议、属性编号相同。

此版本为实验性版本。两款都有历史独立协议实测基础；普通版 HA 适配和多型号隔离有离线测试，
不代表混合型号、不同固件均已通过实机验收。0.7.0b1 有少量计量版实测：六次冷连接的
建连加鉴权仍为 **4.34-8.91 秒**，不含排队和后续读取；已保留会话的开关响应不能当成首次连接性能。
详细样本、已验证项目及仍未验证范围见[收尾与交接](docs/CLOSEOUT.md#已验证与未验证)。
不要用于生命安全设备或不能承受误断电的负载。

## 环境要求

- Home Assistant **2026.10.0 或更新版本**；既有部署验证环境为 2026.10.4。
- HA 所在的 Linux 主机有可用的本地蓝牙适配器、BlueZ 和 D-Bus。
- HA 的 Bluetooth 集成正常工作；容器内能访问 `/run/dbus/system_bus_socket`。
- 当前传输实现使用本机 BlueZ，**不支持 ESPHome 蓝牙代理、手机转发或 Windows HA 主机**。
- 插座先在米家绑定；每台都需要自己的蓝牙 MAC、型号和 **32 字节 `gatt_ltmk`**。
  在 HA 输入时是 **64 个十六进制字符**，不是 16 字节 bindkey、Wi-Fi token 或米家密码。
- 添加或控制时退出手机米家插座控制页；连接被占用时关闭手机蓝牙。

运行时不依赖小米云、不需要手机常驻、不需要另买小米蓝牙 Mesh 网关。
仅可选的扫码工具在获取密钥时访问小米云。

## 安装方式一：HACS（推荐）

这是 **HACS 自定义仓库**，不是 HACS 默认收录，也不是 HA 官方集成。

1. 打开 HA → HACS → 右上角菜单 → 自定义仓库。
2. 仓库填写 `https://github.com/jsdfhasuh/ha-yutai-ble`，类型选择 **Integration / 集成**。
3. 搜索 **Yutai BLE**，下载。
4. **重启 Home Assistant**，无需重启路由器或主机。
5. 按下方“添加插座”完成配置。

后续在 HACS 中对本仓库执行“更新信息”，再“重新下载”新版本并重启 HA。
“更新信息”只刷新版本列表，不会安装代码。更新前保留 HA 备份；完整步骤和回滚见
[安装与维护](docs/INSTALL.md#更新和回滚)。

## 安装方式二：手动 ZIP（不需要 HACS）

1. 从 [Releases](https://github.com/jsdfhasuh/ha-yutai-ble/releases) 下载
   **`yutai-ble-v版本号.zip`**，不要误用扫码工具包。
2. 解压，把 `custom_components/yutai_ble` 放到 HA 配置目录。
   最终应有 `/config/custom_components/yutai_ble/manifest.json`，不要多套一层目录。
3. 重启 HA，按“添加插座”配置。

也可以下载仓库源码、只复制该组件目录，效果与手动 ZIP 相同。
不建议把整个仓库放入 `custom_components`。无需 MQTT、额外加载项或自定义前端卡片。

## 添加插座

1. 在米家添加插座；使用 [Windows 扫码工具](tools/auth/README.md) 获取这台设备的密钥。
2. 在 HA → 设置 → 设备与服务 → 添加集成，搜索 **Yutai BLE / 禹泰蓝牙插座**。
3. 按下表填写名称、蓝牙地址和 `gatt_ltmk`；型号按扫码结果选择普通版或计量版。
4. 添加过程**只读取验证**，不会开关插座或修改设置。若失败，检查供电、手机连接占用和蓝牙距离。
5. 打开设备页，使用“插座总开关”；其他设置和诊断按 HA 原生分组展示。

### 添加页面怎么填写

集成中文名称为 **禹泰蓝牙插座**。在 HA 使用简体中文时，从 0.6.2 起，型号选项
显示中文名称和型号后缀，便于与扫码结果核对：

| 页面中的型号名称 | 扫码结果中的完整型号 | 本集成支持范围 |
| --- | --- | --- |
| **禹泰电工计量版（fsov8m）** | `yutai.plug.fsov8m` | 基础控制、电压/电流/功率、勿扰与双击倒计时设置 |
| **禹泰电工普通版（WY-E802 / fsov7m）** | `yutai.plug.fsov7m` | 基础开关、指示灯、通电默认状态 |

以扫码工具返回的完整型号为准，不按外壳或商品标题猜选。旧版页面若仍只显示
`yutai.plug.fsov8m` / `yutai.plug.fsov7m`，也可按此表对应；炎米 Y1 不在本集成的添加范围内。

| 字段 | 填写方法 |
| --- | --- |
| **设备名称** | 自己取便于识别的名字，例如“客厅插座”“洗衣机插座” |
| **蓝牙地址** | 从扫码工具复制当前插座的地址；格式类似 `XX:XX:XX:XX:XX:XX`，这里的 X 只是格式占位符 |
| **插座型号** | 对照上表，选择扫码结果对应的普通版或计量版 |
| **蓝牙长期密钥（`gatt_ltmk`）** | 复制该插座自己的 **64 个十六进制字符（32 字节）**；不要填米家密码、Wi-Fi token 或 16 字节 bindkey |

提交时只进行本地蓝牙读取验证。连接失败时先核对地址、型号和密钥，确认插座供电、
HA 本地蓝牙正常，并退出可能占用插座连接的米家控制页。
更新后重启 HA；若页面仍显示旧文案，再刷新浏览器并重新打开添加页面。
界面翻译不会改变内部型号、密钥或已有实体 ID，已有设备无需为了中文显示而删除重加。

**以后再买一台受支持的插座，重复以上步骤添加另一个集成条目即可，不用重装插件。**
每台的密钥不能共用；同一地址重复添加会被拦截。恢复出厂或重新绑定后密钥可能变化，
可备份 HA 后删除旧条目并重新添加；实体名称或自动化引用需要核对。

## 断连处理

- 多台插座的业务事务共享串行队列，连接清理后至少冷却 3 秒。
  这不是“硬件只能连一台”的结论；可选保留连接与排队执行事务是两回事。
- 默认每 60 秒轮询；读取失败后间隔退避至 120、240、300 秒，成功后恢复。
- 默认单次连接的后台读取可在确认已断开的瞬时建连失败后重试一次；
  0.7.0b1 另允许手动事务在业务操作开始前有限重连，规则见上方“首次连接”。
- **开关与设置写入永不自动重发**。结果不确定时只重新读取；不会假报成功或把失败当成 0 W。
- 设备断电会不可用，恢复供电后自动重试。不需要不断重启 HA。
- 多设备轮询不是同时采样；设备越多，队列延迟越长，可在集成选项里增大轮询间隔。

### 手动操作与重复连接

从 0.6.0 起，手动命令优先于尚未开始的后台轮询，同优先级仍按提交顺序执行。
后台读取的失败重试等待会给手动命令让路；已经开始的蓝牙事务不会被强行打断。

- 连续重复点击同一操作，在前一次尚未完成且最终验证成功时，共用该次结果。
  “开启 → 关闭 → 开启”不会合并，前一次完成后再次点击也会重新检查设备。
- 排队期间若已有新的完整验证快照，该刷新直接使用快照；待执行的故障恢复读取
  也会检查是否已有后续成功事务，避免重复建连。
- 0.6.x 的排队优化本身不复用连接，默认配置仍独立连接、鉴权、回读并断开。
  0.7.0b1 只有在计量版选项中启用连接保留，才会使用上方的会话复用路径；
  两种路径都不会用旧状态跳过新命令的验证，保留连接可能占用米家直连。
- 写入失败不会自动重发或被当成成功；后续明确提交的命令仍是单独的请求。

计量版的双击倒计时时长以秒输入：1–59 秒，或 60 的整数倍，最大 86340 秒（23 小时 59 分钟）。
这里只配置双击功能，不会主动启动倒计时。

## 隐私与安全

扫码工具在 Windows 当前用户下用 DPAPI 加密保存密钥，不把密钥打印到终端。
HA 配置条目仍需要保存解密后的密钥；密码框只遮挡显示，**不代表 HA 配置文件加密**。
请保护 HA 配置目录、备份和管理员账号，不上传 `.storage`、`private` 或 `target.dpapi`。
扫码工具的剪贴板功能会临时放入明文，使用前关闭剪贴板历史/云同步，粘贴后清空。

## 开发与验证

Python 3.13+，仅标准库即可运行集成及协议模拟测试，不访问 HA 或蓝牙：

```sh
python -B -m unittest discover -s tests -v
python -B -m unittest discover -s tests/protocol -v
python -B -m unittest discover -s research/yutai_fsov7m -v
python -B -m unittest discover -s research/wiing_v7icm -v
python -B tools/build_release.py
```

最后一条生成组件包、独立扫码包及 SHA256 校验文件。仅打包明确列出的文件，
不会打包本地私钥、测试结果、缓存或个人部署脚本。

CI 另设两项环境验证：在 Home Assistant 2026.10.4 的真实协调器中检查失败诊断通知，
以及在 Windows 的 `cmd.exe` 中检查扫码工具的依赖安装恢复。它们分别使用
`python -B -m unittest discover -s tests/ha -v` 和
`python -B -m unittest discover -s tests/windows -v`，与上述模拟测试分开运行。
HA 框架测试需要在独立环境安装该版本 Home Assistant（Python 3.14.2+）；
这些检查仍不会连接蓝牙、登录小米云或操作实际插座。

发布时同步组件 `manifest.json`、版本断言和 `CHANGELOG.md`，并添加
`docs/releases/v版本号.md`。将发布提交的首行写为 `Release v版本号` 后推送到 `main`，
CI 会在所有测试通过后发布该提交的安装包和校验文件，并设为最新版。
普通提交、Pull Request 和手动运行测试不会触发正式发布。
