# 禹泰普通版 / WY-E802

真实型号：`yutai.plug.fsov7m`。这里保留独立研究源码；0.5.0 已把总开关、
指示灯跟随/常灭和通电默认状态接入 HA 配置入口，定时部分仍未提供 HA 控件。

## 文件

| 文件 | 行为 |
| --- | --- |
| `read_probe.py` | 鉴权、F0 验证、只读开关 `(2,1)` |
| `settings_scan.py` | 只读属性扫描，可指定受限子集；默认大范围扫描仅用于研究 |
| `relay_on.py` / `relay_off.py` | 明确设开/关，最多一次 SET，已是目标状态则不写；不自动恢复 |
| `cycle_probe.py` | 空载切换并恢复测试，最多两次 SET，不是日常控制接口 |
| `settings_control.py` | 指示灯跟随/常灭、通电默认关/开/记忆；每次只写一项 |
| `cycle_settings.py` / `local_settings.py` | 纯离线编解码器，无蓝牙 I/O |
| `native_local_control.py` | 带新鲜快照保护的本地定时主开关、子开关、时间和重复设置 |
| `timer_control.py` | 循环参数与主开关、本地时间的受限写入；保留未知位 |
| `test_*.py` | 合成协议回归测试，不操作硬件 |

## 已确认的协议字段

- 开关：`(2,1)`，bool，实际 typelen `0x0001`。
- 指示灯：`(5,4)`，字段 `0xC000`；只确认跟随 `0` 和常灭 `0x8000`。
- 通电默认状态：`(5,4)`，字段 `0x3000`；关 `0`、开 `0x1000`、记忆 `0x2000`。
- 循环计划：`(5,1)`，结束分钟 bit0..10、开始分钟 bit11..21、星期 bit22..28、
  重复 bit29、总开关 bit31；bit30 不解释、不改动。
- 循环开启时长及起始状态：`(5,2)`，低31位秒数、bit31 起始状态。
- 循环关闭时长及结束状态：`(5,3)`，低31位秒数、bit31 结束状态。
- 本地定时总开关：`(5,6)` bit1。
- 本地计划：`(5,7)`，关时间 bit0..10、开时间 bit11..21、星期 bit22..28、
  重复 bit29、关子开关 bit30、开子开关 bit31。
- 两类定时星期：周一/二/三/四/五/六/日对应原始 `0x40/20/10/08/04/02/01`。

除开关外上述字段均为 uint32、typelen `0x5004`。编解码器的数值范围是编码范围，
不是对设备实际允许时长的保证；写入必须保留未确认位并使用刚读取的期望字。

## 实测与未验证项

历史记录确认了独立设置写入/回读/恢复、本地定时自动 ON/OFF、两轮 60/60 秒循环，
以及两类定时星期位的独立映射。独立 ON 命令也收到 ACK，后续重新连接读取仍为 ON。
这是协议级证据，不是带载电压或额定功率测试。

时钟同步、断电后时钟恢复、未来周重复、其他指示灯模式和新 HA 适配的实机运行仍未验收。
完整限制和调用注意事项见 [研究说明](../README.md)；请勿修改型号白名单来试别的插座。
