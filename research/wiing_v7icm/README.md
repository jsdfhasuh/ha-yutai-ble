# AlmLbS 智能插座 / 炎米 Y1

真实型号：`wiing.plug.v7icm`。这是独立研究源码，尚未接入本仓库的 HA 配置入口。

## 文件

- `read_probe.py`：独立 GATT 鉴权、F0 验证、只读 `(2,1)` 开关状态。
- `cycle_probe.py`：空载切换并尝试恢复原状态，不是普通开关服务。
- `test_read_probe.py`、`test_cycle_probe.py`：从相同协议验证套件移植的离线回归测试。
- `vendor`：保持原字节和 MIT 许可证的固定版本协议依赖。

## 2026-10-30 实测结论

该型号在没有手机转发的情况下，通过 Linux 本地蓝牙 GATT 完成鉴权和 F0 验证。
开关属性是 `(siid=2, piid=1)`，type_code=0、typelen=`0x0001`。

一次空载测试读到初始关闭，写入开启并读回开启，随后写回关闭并读回关闭。
总计两次 SET 尝试，测试和恢复均通过验证，结束后确认断开连接。
这证明该实物的直接蓝牙协议路径，不代表 SIG Mesh 标准代理或所有固件兼容。

未测量电气输出，未验证长期稳定性、用电计量、本地定时、循环定时、指示灯、
通电默认状态或断电后的时钟。不能借用禹泰两个型号的设置映射。

使用限制、stdin 凭据要求和离线测试命令见 [研究说明](../README.md)。
本次公开版本只做离线回归，没有重跑真实开关测试。
